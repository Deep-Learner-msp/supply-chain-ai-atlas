# Datasets and benchmarks

| Dataset | Problem | Where |
|---|---|---|
| M5 Forecasting (Walmart) | Hierarchical retail demand | Kaggle competition "M5 Forecasting - Accuracy" |
| DataCo Smart Supply Chain | Orders, shipping, delays | Kaggle |
| Olist Brazilian E-Commerce | Orders, delivery times, reviews | Kaggle |
| CVRPLIB | Capacitated vehicle routing instances | vrp.galgos.inf.puc-rio.br |
| Solomon VRPTW instances | Routing with time windows | Included in CVRPLIB and many solver repos |
| SupplyGraph | Graph-based supply chain planning | [ciol-researchlab/SupplyGraph](https://github.com/ciol-researchlab/SupplyGraph) |
| Corporate emission reports | Extracting Scope 1/2/3 from sustainability reports (LLM fine-tuning) | [nopperl/corporate_emission_reports](https://github.com/nopperl/corporate_emission_reports) |
| Starjob | LLM job-shop scheduling | [arXiv 2503.01877](https://arxiv.org/abs/2503.01877) |

Missing a dataset? Open a pull request with its licence and a one-line description.
